# Quick Start

Learn how to use rocq-of-rust to translate Rust code to Rocq.

## Basic Usage

### Using the Cargo Plugin

In any Rust project directory, generate a `Crate.v` file:

```sh
cargo rocq-of-rust
```

This translates the entire crate to a single Rocq file.

### Using the Standalone Executable

Translate a single Rust file:

```sh
./rocq-of-rust translate --path examples/rust_book/hello_world/hello_world.rs
```

## Command Line Options

### Cargo Plugin

```
Usage: cargo rocq-of-rust [OPTIONS] [-- <RUST_FLAGS>...]

Options:
  --axiomatize    Axiomatize the definitions
  -h, --help      Print help
```

### Standalone Executable

```
Usage: rocq-of-rust [OPTIONS] <COMMAND>

Commands:
  translate    Translate rust files to rocq files
  help         Print help

Options:
  -d, --debug...    Turn debugging information on
  -h, --help        Print help
  -V, --version     Print version
```

#### Translate Subcommand

```
Usage: rocq-of-rust translate [OPTIONS] --path <PATH>

Options:
  -p, --path <PATH>           Path to rust file
  --axiomatize                Axiomatize definitions
  --output-path <OUTPUT>      Output directory [default: rocq_translation]
  -h, --help                  Print help
```

## Example Workflow

### 1. Translate Rust Code

Given a Rust file `example.rs`:

```rust
pub fn factorial(n: u64) -> u64 {
    if n == 0 {
        1
    } else {
        n * factorial(n - 1)
    }
}
```

Run translation:

```sh
cargo rocq-of-rust
```

### 2. Examine Generated Rocq

The output `Crate.v` contains:

```rocq
(* Generated by rocq-of-rust *)
Require Import RocqOfRust.RocqOfRust.

Definition factorial (n : u64) : M u64 :=
  if n =? 0 then
    return 1
  else
    let* result := factorial (n - 1) in
    return (n * result).
```

### 3. Write Proofs

Add a proof file `factorial_proofs.v`:

```rocq
Require Import Crate.

Lemma factorial_positive : forall n,
  factorial n > 0.
Proof.
  induction n.
  - simpl. lia.
  - simpl. (* ... *)
Qed.
```

## Tips

### Handling Version Mismatches

If you see Rust library version errors, copy `rust-toolchain` from the rocq-of-rust repository to your project's root.

### Large Codebases

For large projects:

1. Use `--axiomatize` to generate axiomatized definitions first
2. Verify the translation compiles
3. Remove axiomatization and add proofs incrementally

### Debugging

Enable debug output:

```sh
rocq-of-rust -d translate --path file.rs
```
